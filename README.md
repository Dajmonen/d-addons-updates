# D Addons updates

Downloads for the D addons (WoW Forever) and the DControl Panel desktop app.

**New here?** Download [D-Addons-Setup.exe](https://github.com/Dajmonen/d-addons-updates/releases/download/updates/D-Addons-Setup.exe) and run it.

After that, DControl Panel keeps everything current on its own: it checks this page every 30 minutes and
downloads only the addons that changed. Type `/reload` in game after an update. Updates and notes are on the
app's **Data & settings** page.
